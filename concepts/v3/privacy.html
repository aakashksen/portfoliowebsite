Charon privacy policy

Last updated November 17, 2026

Charon is a personal desktop tool built and used only by Aakash Senthilnathan to manage his own job applications. It is not offered to anyone else.

What it accesses

With the owner's permission, Charon reads the owner's own Gmail through Google's read-only Gmail permission (gmail.readonly). It looks only for recent sign-in and verification codes sent by job application sites, and for replies about the owner's own applications.

What it does with it

  • A code it finds is used once, on the owner's own computer, to finish signing in to the job site that sent it.
  • Email content and codes are not stored, logged, or sent anywhere else. Logs record only that a check happened, the sender's domain, and the outcome.
  • Charon cannot send, delete, or change any email.
  • No data is sold, shared, or used for advertising.

Google user data

Charon's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. The stored sign-in token can also be deleted from the owner's computer.
